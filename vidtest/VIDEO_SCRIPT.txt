PART 5 — VASCO  [2:20 to 3:10]
=======================================================

[ACTION: Click "Open IR" → navigate to vidtest/ → open 4_vasco.txt]

SAY:
  "Now the most powerful analysis — VASCO.
   Flow-sensitive AND context-sensitive.

   This program has a struct Node,
   a global pointer g,
   a function alloc() that does malloc and stores into g,
   and main() that calls alloc() and reads back through g."

[ACTION: Click "VASCO" button]
[ACTION: Click "Analyze"]
[ACTION: Wait for analysis]

SAY:
  "VASCO complete."

[ACTION: Look at the right panel — point to the CONTEXT LOG at the bottom right]

SAY:
  "Look at the context log here.
   VASCO created a separate analysis context for each call.
   START main — context zero.
   CALL to alloc — context one.
   DONE alloc — result memoized.
   If alloc were called again with the same state —
   VASCO would skip the re-analysis. That is the termination guarantee."

[ACTION: Click the "call alloc()" node in the CFG]

SAY:
  "I click the call statement.
   After this call — g is pointing to the malloc'd object.
   That result flowed back from alloc to main —
   through the global variable."

[ACTION: Click the "a = g" node]

SAY:
  "a now also points to the same object.
   b equals a — b points to it too.
   VASCO tracked this precisely — across function boundaries —
   with full context separation."
